# Repository conventions

## Product-neutral language

- Keep source code, identifiers, comments, tests, fixtures, assets, UI copy, documentation, and commit messages product-neutral.
- Do not cite or encode third-party creative applications, vendors, or their terminology as the authority or inspiration for a feature.
- Describe behavior with technical and visual terms, and use vocabulary owned by this project.
- A third-party or external format name is allowed only when it is strictly required at an import, export, or interoperability boundary. Keep that name isolated to the boundary and do not propagate it into internal identifiers.
- Any other exception requires explicit user approval before it is added.
